# 人机校验规则

## 一、源数据完整性

1. 必须收到 `1班.xlsx` 至 `10班.xlsx`，文件数必须为 10。
2. 每个文件只读取第一个工作表；不得跳过无表头文件的首行数据。
3. 自动识别表头：首行包含“姓名”时按表头映射，否则按“姓名 / 学号 / 成绩”顺序读取。
4. 有“备注”列时原样保留；没有该列时留空，不得凭空生成备注。

## 二、结构规范化

1. 班级字段统一为“1班”至“10班”。
2. 姓名删除全角和半角空格，例如“ 张 三 ”规范为“张三”。
3. 学号统一为 9 位文本：`2025` + 两位班级号 + 三位班内序号。
4. 短学号只按所属班级补全，不得跨班猜测。
5. 整行空白必须跳过，并在合并说明中记录跳过的行数。

## 三、成绩与复核

1. `0–100` 的数值成绩计为有效成绩。
2. “缺考”等文本成绩保留原文，不转成 0，也不计入平均分、最高分、最低分和及格率。
3. 超出 `0–100` 的成绩保留原值，标记“疑似录入错误”，不计入有效成绩。
4. 数值 0 分保留原值，标记“请确认是否缺考”，人工未确认前不擅自改写。
5. 异常值不得静默修正；所有规范化与异常记录必须可追溯到源文件和源行号。

## 四、合并结果校验

| 校验项 | 预期结果 | 处理方式 |
| --- | ---: | --- |
| 班级数 | 10 | 不一致则终止提交 |
| 合并记录数 | 102 | 与各班人数汇总逐一核对 |
| 唯一学号数 | 102 | 发现重复则定位并人工确认 |
| 有效成绩数 | 96 | 有效值必须在 0–100 |
| 文本/缺考成绩数 | 3 | 保留原文，不参与分数统计 |
| 超范围成绩数 | 3 | 保留原值并标记复核 |
| 需复核记录数 | 7 | 含 3 条文本、3 条超范围和 1 条 0 分 |
| 姓名重复 | 0 | 当前数据未发现重名 |

## 五、计算复核

1. 有效成绩 96 条，平均分 **77.8**，最高分 **98**，最低分 **0**。
2. 及格率按有效成绩计算：**93 / 96 = 96.88%**。
3. “人数=有效成绩+文本/缺考+超范围”应在每班和总计中同时成立。
4. 班级汇总中的平均分、最高分、最低分和及格率必须由规范化总表重新计算，不能手工抄写。

## 六、人工终检

1. 人工抽查至少 10% 的记录，核对姓名、学号、成绩和备注。
2. 对 3 条文本成绩、3 条超范围成绩和 1 条 0 分记录逐条确认。
3. 核对第 10 班 12 条记录，以及其他班级各 10 条记录。
4. 对无表头的 3 班、含空白行的 7 班、带备注列的 2 班做专项检查。
5. 校验脚本通过不代表原始成绩业务含义正确；成绩纠错仍需任课教师或机房管理员确认。
