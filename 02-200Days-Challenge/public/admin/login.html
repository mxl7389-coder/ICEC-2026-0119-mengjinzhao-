Admin Console · 管理端

登录管理后台

此入口仅接受管理员账号。学生与教师请使用各自的用户端入口。

1此步骤只出现一次，由你本人设置首位管理员。
2创建后在「账号管理」里建立学生 / 教师账号并线下告知。
3使用者从用户端入口登录，自行录入全部业务数据。
系统不预置任何账号与业务数据。密码以 scrypt 加盐哈希保存，任何页面与日志都不会出现明文。
若忘记唯一管理员密码，可在本机运行 node scripts/reset-password.js --reset 账号 重置。
