# 02 · CampusDesk 校园事务台

项目四：解决校园真实痛点的轻量化实用程序研发与日常运行日志验证。

## 目录

| 路径 | 内容 |
| --- | --- |
| `server.js`、`lib/`、`public/` | 完整可运行源码 |
| `scripts/` | 冒烟测试、日报和本机密码重置工具 |
| `process_logs/` | 按自然日保存的脱敏运行日志与日报 |
| `iterations/` | 基于真实日志的 5 份 Git 迭代 Diff |
| `user-feedback/` | 8 位真实使用者的反馈明细与统计 |
| `docs/` | 需求、架构、数据库、测试与使用说明 |
| `CampusDesk_介绍视频.mp4` | 作品介绍视频 |

## 功能

- 通知结构化提取、人工审核、待办和 `.ics` 日历；
- 器材档案、借出、部分归还、全部归还、库存核对与逾期提示；
- 错题归档与 1/2/4/7/15/30 天复习队列；
- 学生、教师、普通管理员和系统管理员角色隔离；
- 本机与局域网访问；
- 脱敏运行日志、SSE 实时日志和日志分析；
- 本地离线规则检索助手，不依赖外部模型服务。

## 启动

在本目录执行：

```powershell
node server.js
```

局域网模式：

```powershell
node server.js --lan
```

## 验证

```powershell
node scripts/smoke-test.js
```

测试使用隔离的业务数据目录和日志目录，结束后自动清理。当前测试脚本包含 132 项断言。

## 交付核对

| 项目四要求 | 当前材料 |
| --- | --- |
| 自动化运行日志 | `process_logs/`，11 个日期、882 条记录；最长连续段 5 天 |
| 基于日志的至少 3 次迭代 Diff | `iterations/`，5 份完整 Diff |
| 完整源码 | `server.js`、`lib/`、`public/`、`scripts/` |
| 8 位真实用户反馈 | `user-feedback/` |

运行日志全部为程序自动写入的原始记录，不补造缺失日期。
