# 测试用例与测试报告 · CampusDesk v6.2.0

> 对应 SRS 第 10 章交付物「测试用例和测试报告」、第 8.3 节「迭代验收 · 提供测试结果」。
> 测试脚本：[`scripts/smoke-test.js`](../scripts/smoke-test.js)：零依赖 Node 编写的端到端 HTTP 冒烟测试，独立端口 5199、独立数据目录 `data/__smoke__/`、独立日志目录 `process_logs/__smoke__/`，跑完自动清理。

---

## 1. 测试环境与方法

| 项目 | 说明 |
| --- | --- |
| 被测服务 | `server.js`，由测试脚本以子进程启动，注入隔离环境变量 |
| 端口 | 5199（与日常服务 5174 隔离，不冲突） |
| 数据隔离 | `CAMPUSDESK_DATA_DIR = data/__smoke__/`；业务数据只在隔离目录产生 |
| 日志隔离 | `CAMPUSDESK_LOG_DIR = process_logs/__smoke__/` + `CAMPUSDESK_LOG_SOURCE = smoke` |
| 清理 | 测试结束删除两个隔离目录 |
| 请求方式 | 原生 `http` 模块构造请求，覆盖 GET / POST / DELETE、Cookie 会话、SSE 流、自定义 Header |
| 断言方式 | `check(name, condition, detail)` 逐项累积，最后输出「通过数 / 总数」，任一失败即以非 0 退出码结束 |

**不会污染真实数据**：脚本含一条专门断言，核对测试前后主日志行数不变且主日志中不存在 `source === 'smoke'` 的记录。

## 3. 关键测试用例举例

| 用例 ID | 输入 | 期望结果 |
| --- | --- | --- |
| TC-AUTH-01 | 未登录 `GET /user/index.html` | 302 → `/user/login.html` |
| TC-AUTH-02 | 管理员账号从 `/user/` 登录 | `PORTAL_MISMATCH`，且校验发生在密码正确之后（防账号枚举） |
| TC-DATA-01 | 全新隔离目录启动后 `GET /api/bootstrap` | 8 个业务/系统数据集均为 `[]`，`initialized: false` |
| TC-NOTICE-01 | 粘贴中文通知 → `/api/notice/parse` | 返回标题、截止、地点、对象、待办、置信度、缺失字段清单 |
| TC-NOTICE-02 | 客户端伪造 `notice.id` 保存 | 服务端忽略并生成新 id，不产生同 id 记录 |
| TC-IMPORT-01 | 分别以 5 种 `import_type` 提交 | 全部 200，返回一致的结构化字段 |
| TC-DUP-01 | 提交高度相似的通知原文 | 返回相似度提示，不泄露他人标题或原文 |
| TC-ICS-01 | `remind_minutes = 0` / `30` / `1440` | 分别生成无 `VALARM` / `-PT30M` / `-P1D` |
| TC-LOAN-01 | 学生归还他人借用记录 | 403 `FORBIDDEN`，记录状态不变 |
| TC-LOG-01 | 请求 `/api/health/%E0%A4%A`（畸形 URL） | 400 且服务存活；后续 `/api/health` 仍 200 |
| TC-LOG-02 | 写入 `Origin: http://evil.example` 的 POST | 403 `CSRF_ORIGIN_MISMATCH` |
| TC-LOG-03 | 测试结束后读主日志 | 行数不变、无 `smoke` 来源记录 |
| TC-BACKUP-01 | 导出备份 → 篡改 datasets → 校验 | 校验失败，拒绝恢复 |
| TC-BACKUP-02 | 未带确认标记调用恢复 | 拒绝执行；恢复不覆盖 `users` / `sessions` |
| TC-AI-01 | 未登录 `POST /api/assistant/ask` | 401 |
| TC-AI-02 | 询问「最近的截止是什么」 | 回答附 `sources`（类型 / id / 字段 / 值） |
| TC-AI-03 | 库中无任何数据时提问 | 明确「本地还没有…」/「无法作答」，不编造 |

## 6. 测试范围与口径说明

- **界面验证方式**：静态 DOM 引用核对 + 手工真实访问验证，覆盖三套入口与主要交互路径。
- **耗时数据来源**：真实运行日志（p50 1.63 ms / p95 79.96 ms），反映开发与使用场景下的单次请求耗时。
- **数据层测试范围**：覆盖 JSON 原子写入、文件指纹缓存失效与跨进程一致性；审计与业务写入分别落盘。
- **ICS 特殊字符**：标题含裸 CR / UID 注入、非整数提醒分钟的边界由代码审查与手工验证覆盖。
- **SSE 长时间断线**：游标补齐逻辑已修正（只推进到实际取回行），覆盖断线重连与按游标补齐两类用例。
