# raw_data · 课题 04 原始数据说明

本目录存放**本人实地采集**的原始记录，仓库中当前只有空白模板。

| 文件 | 状态 | 说明 |
| --- | --- | --- |
| `排队时序记录表.csv` | 空白模板 | 15 行、8 列；仅预填序号与相对分钟，所有数值列为空 |
| `photos/` | 空目录 | 放本人实拍的现场照片 |

## CSV 填写规范

- 用记事本、VS Code 或 Excel 打开；若 Excel 打开中文乱码，把文件另存为「UTF-8 带 BOM」即可，内容和列名不要改。
- **不要改表头**，分析脚本按列名取值。
- 数值只写数字，不带单位（`12` 而不是 `12人`）。
- 测不到就留空，并在 `备注` 写原因；**不要估算、不要事后回忆补数**。
- 保留原始文件，不要把填完的表复制成新文件再改，避免版本混乱。

## 照片规范

题目虽未对本课题强制要求照片，但阶段一目录要求「照片与 raw_data」，建议拍 2 张作为现场证据：

| 建议文件名 | 内容 |
| --- | --- |
| `T00-排队起点.jpg` | 开始观察时的队列全景 |
| `T28-排队结束.jpg` | 收工时的队列全景 |

- 拍队列与窗口关系即可，**避免拍到同学正脸和学号/饭卡等个人信息**。
- 手机原图直接放进来，不要加滤镜；文件名中的时间可改成你的真实时段。
- 若不便拍摄，可在本文件末尾补一句说明，不要找网图代替。
