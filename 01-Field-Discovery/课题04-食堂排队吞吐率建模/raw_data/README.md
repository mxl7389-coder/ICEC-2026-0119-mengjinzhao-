# raw_data · 课题 04 数据说明

## 文件

| 文件 | 内容 |
| --- | --- |
| `示例_模拟数据_非实测.csv` | 15 组排队时序记录，每 2 分钟一组，覆盖 30 分钟 |

数据集按公开研究中常见的单窗口排队参数构造（服务时长 33–45 秒、到达率 1–3.5 人/分钟、窗口数恒为 1），每行 `备注` 列标注「模拟数据-非实测」。它是本课题指标计算、瓶颈定位、改进方案推算与 3 张图的统一数据源。

## 字段

| 列 | 单位 | 含义 |
| --- | --- | --- |
| `序号` | — | 1–15 |
| `时点(min)` | 分钟 | 从观测起点起的第 2、4、…、30 分钟 |
| `观测时间` | HH:MM | 该组对应的钟点 |
| `队列长度(人)` | 人 | 该时点队伍中的人数，含正在接受服务者 |
| `本时段到达人数(人)` | 人 | 该 2 分钟区间内新排进队尾的人数 |
| `窗口数` | 个 | 同时开放的打饭位，本数据集恒为 1 |
| `单人服务时长(s)` | 秒 | 单人从到窗口到离开的平均秒数 |
| `备注` | — | 数据性质标记 |

## 派生指标口径

| 指标 | 计算式 |
| --- | --- |
| 到达率 λ | 本时段到达人数 ÷ 2（人/分钟） |
| 服务率 μ | 窗口数 × 60 ÷ 单人服务时长（人/分钟） |
| 利用率 ρ | λ ÷ μ |
| 平均等待 W | 队列长度 L ÷ λ × 60（秒） |
| 累计离开 | Σ(μ × 2)，理论服务能力 |

## 复现

在本课题目录执行 `node 复算.js`（零依赖），脚本读取本目录 CSV，重算 λ、μ、ρ、W 等 23 项指标并与 `report/统计结果.json` 逐项比对，输出 PASS。生成 `figs/` 下 3 张图的 `出图.py` 为 Python 版，需 pandas、matplotlib。

文件编码为 UTF-8 带 BOM，Excel 可直接打开且中文不乱码；表头与列名是脚本取数依据，不要修改。
