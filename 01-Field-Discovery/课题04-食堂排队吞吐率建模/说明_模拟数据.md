# 示例数据集说明 · 课题 04

`raw_data/示例_模拟数据_非实测.csv` 是本课题 `report/分析报告.md` 与 `figs/` 三张图共用的数据源，共 15 组、每 2 分钟一组、覆盖 30 分钟。每行 `备注` 列均写有「模拟数据-非实测」。

## 构造依据

按公开研究中常见的单窗口食堂排队参数生成：

| 参数 | 取值 |
| --- | --- |
| 服务窗口数 | 恒为 1 |
| 单人服务时长 | 33–45 秒，高峰段上升、后段回落 |
| 每 2 分钟到达人数 | 2–7 人（对应到达率 1.0–3.5 人/分钟） |
| 队列长度 | 由到达与服务的累计差形成，先升后稳再小幅回落 |
| 观测时间 | 12:02–12:30，每 2 分钟一行 |

## 用途

1. 作为 15 组排队时序表，逐行计算 λ、μ、ρ、W 与累计到达/离开。
2. 由 `出图.py` 生成 `figs/fig1_queue.png`（队列长度时序）、`fig2_lambda_mu.png`（到达率与服务率对比）、`fig3_cumulative.png`（累计到达与累计离开）。
3. 作为 `report/分析报告.md` 中瓶颈定位与低成本改进方案推算的统一依据，报告里每个数字都能在这张表里找到出处。

## 性质与适用范围

这是一份按公开参数构造的示例序列，不是本校食堂的实地采样读数。`report/分析报告.md` 的数值结论以这份数据集为界，用于演示「时序记录 → 指标计算 → 瓶颈定位 → 改进方案推算」的完整链路；换用别的数据源后，重跑 `node 复算.js` 可核对同口径的全部指标，图由 `出图.py` 生成。

数据性质在文件名、CSV 备注列、本文件、数据集 README 与报告开头五处显式标明，任何引用该表的图表与结论都沿用同一标注。
