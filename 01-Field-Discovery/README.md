# 阶段一 · 田野调研（Field Discovery）

> 课程建议目录：阶段一报告、照片与 `raw_data/`。

## 本目录已有文件

| 文件 | 性质 |
| --- | --- |
| `README.md` | 目录说明与待补清单（本文） |
| `选题依据与痛点分析.md` | **已补齐**：基于课程题干真实痛点与实际代码整理的选题论证、需求优先级、功能映射、本地优先取舍 |

> 上述分析文档是**论证与整理**，不是访谈原始数据；不包含虚构的访谈对象、照片或问卷统计。

阶段二的实际选题依据来自项目四题干列出的校园真实痛点（通知分散、器材账实不符、错题整理耗时），程序内对应的三个模块为：

| 痛点 | 对应模块 | 代码位置 |
| --- | --- | --- |
| 通知分散、截止时间易漏 | 通知结构化提取 + 待办 + `.ics` | `lib/extractor.js`、`lib/api.js` 的 `notice.*` |
| 器材"账上有、柜里没有" | 器材档案 + 借还 + 库存重算 + 逾期 | `lib/api.js` 的 `equipment.*` / `loan.*` |
| 错题抄完不再看 | 按 1/2/4/7/15/30 天间隔复习 | `lib/api.js` 的 `mistake.*` |
