## 阶段二（项目四）选题依据

来自项目四题干列出的校园真实痛点（通知分散、器材账实不符、错题整理耗时）：

| 痛点 | 对应模块 | 代码位置 |
| --- | --- | --- |
| 通知分散、截止时间易漏 | 通知结构化提取 + 待办 + `.ics` | `lib/extractor.js`、`lib/api.js` 的 `notice.*` |
| 器材"账上有、柜里没有" | 器材档案 + 借还 + 库存重算 + 逾期 | `lib/api.js` 的 `equipment.*` / `loan.*` |
| 错题抄完不再看 | 按 1/2/4/7/15/30 天间隔复习 | `lib/api.js` 的 `mistake.*` |

## 复现

在任一课题目录执行（零依赖，只需 Node.js）：

```
node 复算.js
```

脚本读取该目录 `raw_data/` 下的数据集，重算全部指标并与 `report/统计结果.json` 逐项比对，输出 PASS 与关键数值。`figs/` 下的 PNG 由 `出图.py` 生成（Python 版，需 pandas 与 matplotlib），图已随仓库归档，无需重新生成。
