# 校验规则（6 项一致性检查）

记录完成、出图之前，逐条过一遍。任一条不过，先改数据再画图，否则图表会替你说谎。

## R1 时间先后
`结束时间` 必须晚于 `开始时间`，且两者都在同一天内（跨零点的任务拆成两条记）。

## R2 时长自洽
`实际时长(min)` = 结束时间 − 开始时间，允许 ±2 分钟误差（取整造成）。
超过 2 分钟误差说明时间记错了，不是取整问题。

## R3 专注不超实际
`专注时长(min)` ≤ `实际时长(min)`，且差额应大致等于“中断次数 × 单次中断平均时长”。
专注时长大于实际时长 = 直接作废该条。

## R4 类型枚举
`类型` 只能是：学习、创作、事务、娱乐、社交。写“其他”要改到最接近的一类，不允许为空值。

## R5 日总量合理
同一天所有任务 `实际时长` 合计 ≤ 960 分钟（16 小时清醒时间）。超过说明有重叠记录（多任务同时记），需要拆分或删重。

## R6 中断与原因匹配
`中断次数` > 0 时，`中断原因` 不能为空；`中断次数` = 0 时，原因应为空白值。
原因只写一个主因，多个原因用“/”分隔，便于帕累托统计。
