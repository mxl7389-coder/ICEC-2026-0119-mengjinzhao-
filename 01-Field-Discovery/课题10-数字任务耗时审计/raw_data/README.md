# raw_data · 课题 10 原始数据说明

本目录存放**本人真实采集**的输入样本、Prompt 存档与计时记录。仓库中当前只有空白模板与方法论文档。

| 路径 | 状态 | 说明 |
| --- | --- | --- |
| `耗时对比记录表.csv` | 空白模板 | 10 行、10 列；仅预填样本编号 S01~S10，所有数值与判定列为空 |
| `样本/` | 空目录 | 放 `S01.txt` ~ `S10.txt`，本人从真实班群/教务通知脱敏后复制 |
| `prompts/Prompt模板.md` | 已写好 | 可直接复制使用的 Prompt，属于交付物 |
| `prompts/` | 需追加 | 本人实际使用过的 Prompt 原文存档，文件名带日期 |

## 样本规范

- 10 条必须是**真实来源**，删掉姓名、学号、手机号、群昵称、班级；保留日期、地点、事项。
- 每条一个纯文本文件，文件名与 CSV 的 `样本编号` 一致。
- 不要编造通知内容；样本挑选的多样性建议见 `../采样方案.md` 第二节。

## CSV 填写规范

- 表头不要改，分析脚本按列名取值；中文乱码时另存为 UTF-8 带 BOM。
- 耗时只写数字（秒），不带单位；正确性两列只写 `是` 或 `否`。
- 返工次数写整数，没有就写 `0`。
- `使用的Prompt文件` 写你实际用的那个文件名，如 `Prompt-2026-11-24.md`。
- 漏计时的样本重测，不要凭印象补数。

> 隐私提醒：样本与 Prompt 会随仓库公开。提交前再检查一遍有没有残留姓名、学号、手机号、群名。
