# raw_data · 课题 10 数据说明

## 文件

| 路径 | 内容 |
| --- | --- |
| `示例_模拟数据_非实测.csv` | 17 条数字任务记录，覆盖 2026-11-18 至 2026-11-24 共 7 天 |
| `prompts/Prompt模板.md` | 校园通知结构化抽取 Prompt，5 字段 JSON 输出 |
| `prompts/01_数据校验.md` | 让 AI 按 6 项一致性规则查错，只报问题、不改数 |
| `prompts/02_汇总与归因.md` | 让 AI 按类型汇总、找异常、排中断原因 |
| `prompts/03_报告成文.md` | 按报告结构成文，限定只用表中数值 |

数据集是为演示时间结构、计划偏差、专注率与中断归因而构造的示例序列，每行 `备注` 列标注「模拟数据-非实测」。它是本课题 `report/分析报告.md`、`figs/` 下 4 张图与 `report/统计结果.json` 的统一数据源。

## 字段

| 列 | 格式 | 含义 |
| --- | --- | --- |
| `序号` | 整数 | 1–17 |
| `日期` | YYYY-MM-DD | 任务所在日 |
| `任务名称` | 文本 | 具体任务 |
| `类型` | 枚举 | 学习 / 创作 / 事务 / 娱乐 / 社交 |
| `计划时长(min)` | 整数 | 开始前预估 |
| `开始时间` / `结束时间` | HH:MM | 24 小时制 |
| `实际时长(min)` | 整数 | 结束 − 开始 |
| `中断次数` | 整数 | 中途离开次数 |
| `中断原因` | 文本 | 单一主因 |
| `专注时长(min)` | 整数 | ≤ 实际时长，5 分钟粒度估算 |
| `完成度%` | 0–100 | 任务结束时自评 |
| `备注` | — | 数据性质标记 |

## 派生指标口径

- 计划偏差率 = (实际 − 计划) ÷ 计划 × 100%
- 专注率 = 专注时长 ÷ 实际时长 × 100%
- 中断密度 = 中断次数 ÷ (实际时长 ÷ 60)，次/小时
- 时间结构占比 = 各类型实际时长 ÷ 总实际时长

## 一致性校验

`report/一致性校验规则.md` 定义 R1–R6 六项规则；`出图.py` 运行时自动执行 R2（时长自洽）与 R3（专注不超实际）。本数据集 17 条记录 6 项规则全部通过，逐日合计与逐条结果见 `report/统计结果.json`。

## 复现

在本课题目录执行 `node 复算.js`（零依赖），脚本读取本目录 CSV，重算汇总指标与 6 项校验并与 `report/统计结果.json` 逐项比对，输出 PASS。生成 `figs/` 下 4 张图的 `出图.py` 为 Python 版，需 pandas、matplotlib。文件编码为 UTF-8 带 BOM；表头与列名是脚本取数依据，不要修改。
