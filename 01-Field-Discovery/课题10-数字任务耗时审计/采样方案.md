# 课题 10 · 日常数字任务耗时审计与 AI 批处理实证 · 方法与字段定义

> 题目要求：记录一项高频重复性数字任务（表格汇总、文件重命名、笔记提取等），**对比人工与 AI 脚本/Prompt/工作流处理 10 个样本的耗时**；交付任务样本、AI 脚本/Prompt 与耗时对比表，制定人机校验规则。
> 本课题当前分析所用的 17 条任务记录见 `raw_data/示例_模拟数据_非实测.csv`，其构造依据见 `说明_模拟数据.md`；计算结论见 `report/分析报告.md`。

## 一、任务范围

只记**有明确起止的数字化任务**，按五类归档：

| 类型 | 典型任务 |
| --- | --- |
| 学习 | 写课程报告、复习 PPT、看网课、刷题库 |
| 创作 | 剪视频、做海报、写代码、调模型 |
| 事务 | 填表、发通知、整理文件、回复消息 |
| 娱乐 | 刷短视频、看番、游戏 |
| 社交 | 长聊、视频通话 |

吃饭、走路、睡觉、纯发呆不计入。抽取类任务以「把班群 / 教务通知整理成结构化表格」为代表：每条抽出 `事项`、`日期`、`时间`、`地点`、`截止日期` 五个字段，结果对错可逐字段核对，适合制定校验规则。

## 二、字段定义

| 列名 | 格式 | 定义 |
| --- | --- | --- |
| `日期` | YYYY-MM-DD | 跨天任务拆成两条 |
| `任务名称` | 文本 | 具体到能复述 |
| `类型` | 枚举 | 学习 / 创作 / 事务 / 娱乐 / 社交 |
| `计划时长(min)` | 整数 | 开始前预估 |
| `开始时间` / `结束时间` | HH:MM | 24 小时制 |
| `实际时长(min)` | 整数 | 结束 − 开始 |
| `中断次数` | 整数 | 中途离开或切走的次数 |
| `中断原因` | 文本 | 单一主因；次数为 0 时该格为空 |
| `专注时长(min)` | 整数 | ≤ 实际时长，5 分钟粒度估算 |
| `完成度%` | 0–100 | 任务结束时自评 |

## 三、核心指标

- 计划偏差率 = (实际 − 计划) ÷ 计划 × 100%
- 专注率 = 专注时长 ÷ 实际时长 × 100%
- 中断密度 = 中断次数 ÷ (实际时长 ÷ 60)，次/小时
- 时间结构占比 = 各类型实际时长 ÷ 总实际时长

## 四、AI 脚本 / Prompt 工作流

| 环节 | 文件 | 职责 |
| --- | --- | --- |
| 人工登记 | `raw_data/示例_模拟数据_非实测.csv` | 逐条记录起止、中断与专注 |
| 数据校验 | `raw_data/prompts/01_数据校验.md` | 按 6 项规则逐行查错，只报问题不改数 |
| 汇总归因 | `raw_data/prompts/02_汇总与归因.md` | 按类型汇总、找异常、排中断原因 |
| 报告成文 | `raw_data/prompts/03_报告成文.md` | 按骨架成文，只用表中数值 |
| 抽取 Prompt | `raw_data/prompts/Prompt模板.md` | 5 字段 JSON，原文没写的一律填「未提及」 |
| 脚本批处理 | `出图.py` | 读取 CSV、自动执行 R2/R3 校验、汇总、输出 4 张图 |

三份辅助 Prompt 共同规定「只使用表中真实数值、缺数据的项写数据不足、不新增或推断数字」，把生成式幻觉挡在汇总环节之前。

## 五、人机校验规则

`report/人机校验规则.md` 定义三层校验：L1 输入合规（人工，采样前一次做完）、L2 输出格式（脚本或人工扫一眼）、L3 字段语义（必须人工逐字段比对）。风险分绿（直接采用）、黄（人工复核）、红（拒绝采用）三级，原则是「未提及不算错误，编造才算错误」。

`report/一致性校验规则.md` 定义 R1–R6 六项数据一致性检查（时间先后、时长自洽、专注不超实际、类型枚举、日总量合理、中断与原因匹配）。本数据集 17 条记录六项全部通过，`出图.py` 运行时自动执行其中的 R2 与 R3。

## 六、正确性判定与公平性口径

抽取类任务中，5 个字段**全对**才算该条正确；任一字段有误即计入返工次数。人工组与 AI 组使用同一批样本、同一张结果表、同一个计时口径（从看到样本到字段写入并确认无误，含粘贴与核对）；AI 组顺序打乱，两组之间休息，全程同一模型、同一 Prompt。报告须同时给出提速倍数与正确率，只报提速属于误导。
