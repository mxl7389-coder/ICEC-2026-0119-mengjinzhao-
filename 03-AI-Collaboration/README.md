## 人工核验

1. 每次改动先运行 JavaScript 语法检查。
2. 运行 `node scripts/smoke-test.js`，确认断言实际执行且全部通过。
3. 检查测试数据与测试日志只在隔离目录产生并已清理。
4. 用真实浏览器验证登录、权限隔离、页面跳转和局域网访问。
5. 对照原始日志、最终工作簿和汇总表复核关键数字。
6. 不补造缺失日志，不虚构用户反馈，不把测试结果当作真实使用。
