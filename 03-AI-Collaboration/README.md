## 使用原则

- AI 只用于**定位问题、解释原因、给出改法**；所有代码改动都经过本地 `scripts/smoke-test.js` 回归验证后才提交。
- 所有「已实现 / 规划中」的功能状态以代码为准，AI 不替程序承诺未实现的能力（OCR、本地大模型、RAG、SQLite 迁移均标为规划中）。
- 运行日志、用户反馈、账号与业务数据一律由真实运行 / 真实用户产生，AI 不代填。
