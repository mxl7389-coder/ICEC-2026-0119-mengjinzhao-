## 4. 日志字段与脱敏

单条记录示例：

```json
{"ts":"2026-11-11T09:12:33.123Z","day":"2026-11-11","app_version":"v6.2.0","source":"live","session":"a1b2c3d4e5f6","role":"student","module":"notice","action":"parse","status":"ok","duration_ms":3.42,"error_code":null,"meta":{"input_len":128,"hit_rules":7,"confidence":88}}
```

**不写入**：通知原文、姓名、题目内容、反馈正文、密码、会话 token 明文、业务数据内容。符合 SRS 4.3「敏感信息不得写入普通运行日志」。

## 5. 日志采集与同步机制

每次 HTTP 请求结束时，`lib/telemetry.js` 向当日 `process_logs/YYYY-MM-DD.jsonl` 追加一条脱敏记录；`scripts/daily-report.js --sync` 生成 `process_logs/summary-YYYY-MM-DD.md` 并自动提交。日报包含按模块 / 动作 / 角色 / 版本 / 错误码的聚合，以及连续段、历史最长连续与无记录日期的统计，是生成时刻的静态快照。

- 冒烟测试通过 `CAMPUSDESK_LOG_DIR` 写入 `process_logs/__smoke__/`，跑完即删，不进入真实 telemetry。
- v6.1 起日志带 `source` 字段（`live` / `legacy` / `smoke`），早期不含该字段的历史记录在日报中按 `legacy` 口径说明。
- 会话标识为不可逆哈希；日志不含通知原文、姓名、学号、反馈正文、账号或口令。
