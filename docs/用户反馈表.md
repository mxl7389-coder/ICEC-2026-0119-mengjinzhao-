> 收集完成后，可在网站「使用反馈」页面逐条录入，或保留本表原件作为附件。

## 填写指引

让每位同学实际完成至少一项真实任务，再填写：

1. **通知提取**：从班群 / 教务通知里找一条真实通知，粘贴后看时间、地点、待办是否提取正确。
2. **器材借还**：登记一次借用（可用昵称），再登记归还，看库存数字与逾期提示是否正确。
3. **错题归档**：录入一道真实错题，第二天回来完成一次复习。
4. **运行日志**：看一眼「运行日志」页，确认自己刚才的操作被记录、且没有出现自己的姓名或通知原文。

评分请按真实感受给，1 分和 5 分都比一律 4 分更有价值。若发现问题，请写清楚 "做了什么 → 期望什么 → 实际怎样"。
