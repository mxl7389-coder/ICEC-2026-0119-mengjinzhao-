评分点自查

要求分值本项目的落地方式状态
连续 ≥7 天自动化运行日志
脱敏时间戳、调用频次、耗时、报错，每日同步 process_logs/		25每次请求由 lib/telemetry.js 自动写 JSONL；scripts/daily-report.js --sync 生成日报并每日提交需连续运行 7 天
基于日志的 ≥3 次 Git 迭代 Diff20v1 基础版 → v2 按日志暴露的解析缺陷修复 → v3 按耗时/报错数据优化，详见 README「Git 迭代记录」与 git log --stat已具备
完整源码 + 8 位真实用户反馈15源码全部在本仓库；反馈表单 + docs/用户反馈表.md 空白模板，需由 8 位真实同学填写源码已备 / 反馈待真人填写

怎么跑起来

node server.js
# 打开 http://localhost:5173

# 每日收工前同步日志
node scripts/daily-report.js --sync
git push

零第三方依赖，Node.js 18+ 即可。数据保存在 data/*.json，日志在 process_logs/。

目录结构

server.js            本地 HTTP 服务
lib/telemetry.js     自动脱敏运行日志
lib/extractor.js     中文通知结构化引擎
lib/api.js           三大工具业务接口
lib/store.js         JSON 原子存储
public/              前端页面（离线可用）
scripts/             日报 / 冒烟测试
data/                业务数据
process_logs/        每日 telemetry + 日报
docs/                反馈表 / 迭代记录

隐私说明

日志里不写通知原文、姓名、学号、题目内容与反馈正文，只保留长度、条数、命中规则数、耗时、状态码、错误码等可统计特征；会话标识为不可逆哈希。业务数据仅保存在本机 data/，是否同步到 GitHub 由你决定（.gitignore 默认排除 data/，只提交日志）。
