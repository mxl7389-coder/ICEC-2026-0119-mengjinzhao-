项目说明

对应「项目四：解决校园真实痛点的轻量化实用程序研发与日常运行日志验证」。

三个角色，各司其职

角色入口可以做的事
学生/index.html录入并查看自己的通知待办与错题、登记器材借还、提交真实反馈
教师/index.html学生全部能力 + 新增/删除器材、查看全部通知与错题、查看反馈汇总
管理员/admin.html实时运行日志（SSE 推送）、错误码聚合、账号管理、每日日志汇总与数据总览
账号全部由使用者创建：首次打开时由你设置第一位管理员，其余账号由管理员在后台创建。系统不预置任何账号、器材、通知、错题或反馈。

怎么跑起来

node server.js
# 浏览器打开 http://localhost:5173/login.html
# 端口被占用时会自动顺延，终端会打印实际地址

# 每日收工前同步日志
node scripts/daily-report.js --sync
git push

零第三方依赖，Node.js 18+ 即可。业务数据保存在 data/*.json，运行日志在 process_logs/。

目录结构

server.js            HTTP 服务 / SSE 实时流
lib/auth.js          账号、密码哈希、会话与权限
lib/telemetry.js     自动脱敏运行日志
lib/extractor.js     中文通知结构化引擎
lib/api.js           业务接口 + 管理后台接口
lib/store.js         JSON 原子存储
public/login.html    登录 / 首次初始化
public/index.html    学生 / 教师工作台
public/admin.html    管理员实时日志后台
scripts/             日报 / 冒烟测试
data/                业务数据（全部由用户录入）
process_logs/        每日 telemetry + 日报

隐私说明

日志里不写通知原文、姓名、学号、题目内容与反馈正文，只保留长度、条数、命中规则数、耗时、状态码、错误码、角色等可统计特征；会话标识为不可逆哈希，密码以 scrypt 加盐哈希保存。业务数据仅保存在本机 data/，是否同步到 GitHub 由你决定（.gitignore 默认排除 data/，只提交日志）。

修改密码

修改后当前会话保持有效，其它设备的登录会失效。
